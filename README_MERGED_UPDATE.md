# Live Queue Sorting + Collapsible Dashboard Panels

This package preserves the latest three-column collapsible dashboard panels and adds server-side sorting to the Live Appointment Queue.

Preserved UI behavior:
- Global AI Warehouse Copilot remains at the top.
- Watch Operating Conditions, AI Prediction Center, and Live What-If Simulation remain collapsible.
- All three are closed by default.
- Collapsed cards appear next to each other on desktop.
- Expanded panels use full width.

Added behavior:
- Sortable queue columns with ascending, descending, and default operational order.
- Sorting persists across pages and uses the complete filtered backend dataset.
